# ar_marker_meter_gui.py 実装仕様

このドキュメントは、`ar_marker_meter_gui.py` の依存関係、画面構成、主要処理、関連ファイルをまとめたものです。

## 概要

`ar_marker_meter_gui.py` は、ARマーカーを基準にアナログメーターの位置を登録し、登録情報から針と指示値を検出するための PySide GUI アプリです。

主な目的は次の通りです。

- 画像を開いてメーター円を手動または自動で設定する
- ARマーカーからメーター円までの相対位置を登録する
- 最小目盛り、最大目盛りの位置と値を登録する
- 登録済み情報からメーター位置を復元して針を検出する
- 針の角度からメーター指示値を計算する
- 検出結果をプレビュー表示し、画像として保存する

## 起動方法

PowerShell では、仮想環境の Python を直接指定して起動できます。

```powershell
& ..\..\scripts\python.exe .\ar_marker_meter_gui.py
```

`activate` を使う場合は、環境によって PowerShell の実行ポリシーで止まることがあります。その場合は上記のように `python.exe` を直接呼び出します。

## 外部依存関係

| 依存 | 用途 |
| --- | --- |
| PySide6 または PySide2 | GUI 表示、ボタン、入力欄、画像表示、イベント処理 |
| OpenCV (`cv2`) | 画像読み込み、色変換、描画、ARマーカー検出、円検出、針検出 |
| NumPy | ARマーカー座標変換、ホモグラフィ変換、幾何計算 |

PySide は最初に PySide6 を import し、失敗した場合は PySide2 を使います。どちらもない場合は起動時にエラーになります。

## 主なクラス

### `ImageView`

画像表示用の `QLabel` 拡張クラスです。

主な役割:

- OpenCV の BGR 画像を Qt の `QImage` / `QPixmap` に変換して表示する
- ウィンドウサイズに合わせてアスペクト比を保ったまま画像を拡大縮小する
- 画面上のクリック座標を、元の処理画像座標へ変換する
- 左クリックとドラッグで座標を `clicked(int, int)` シグナルとして通知する

### `ArMarkerMeterWindow`

アプリ本体の `QMainWindow` です。

主な役割:

- 画像、登録ファイル、ARマーカー、メーター円、目盛り点、検出済み針の状態管理
- GUI 部品の生成とイベント接続
- メーター円、目盛り、ARマーカー登録の操作
- 登録済み情報からの針検出と値計算
- プレビュー画像の更新と保存

## 画面構成

左側に画像プレビュー、右側に操作パネルがあります。

操作パネルの主な項目:

| UI | 内容 |
| --- | --- |
| 画像を開く | 処理対象画像を変更する |
| 登録読込 | `ar_marker_meter_config.json` などの登録ファイルを読み込む |
| 設定先変更 | 登録ファイルの保存先を変更する |
| 辞書 | ArUco マーカー辞書を選択する |
| マーカーID | 検出対象のマーカーID。`-1` の場合は自動選択 |
| 処理最大幅 | 大きい画像を処理前に縮小する最大幅 |
| クリック操作 | 画像クリック時に、円中心・最小目盛り・最大目盛りのどれを設定するか選ぶ |
| 中心 X / Y、半径 | メーター円の手動指定 |
| 最小値 / 最大値 | min/max 目盛りに対応する値 |
| 目盛り方向 | min から max へ向かう方向。時計回りまたは反時計回り |
| 文字列を描画 | marker id、min/max、needle 角度などの文字表示を切り替える |

主なボタン:

| ボタン | 処理 |
| --- | --- |
| マーカー検出 | 現在画像から ARマーカーを検出する |
| メーター円を自動検出 | 画像からメーター円を推定する |
| 目盛りを自動設定 | 現在の円を基準に min/max 点を自動配置する |
| 目盛り登録をクリア | min/max 点を消去する |
| この円と目盛りで登録保存 | ARマーカー基準の登録情報を JSON に保存する |
| 登録から針と値を検出 | 登録情報を使って針と指示値を検出する |
| 表示画像を保存 | 現在のプレビュー画像を `output/` に保存する |
| 円を中央へ戻す | メーター円を画像中央に戻す |

## 登録ファイルの内容

登録ファイルは `MarkerMeterRegistration` の内容を JSON として保存します。

主な項目:

| 項目 | 内容 |
| --- | --- |
| `dictionary` | 使用する ArUco 辞書 |
| `marker_id` | 登録対象のマーカーID |
| `center_rel_x`, `center_rel_y` | ARマーカー座標系でのメーター中心 |
| `radius_rel` | ARマーカー座標系でのメーター半径 |
| `max_width` | 登録時の処理最大幅 |
| `registration_image` | 登録時に使った画像 |
| `registration_circle_x`, `registration_circle_y`, `registration_circle_radius` | 登録時画像上のメーター円 |
| `scale_min_value`, `scale_max_value` | min/max 目盛りの値 |
| `scale_min_rel_x`, `scale_min_rel_y` | ARマーカー座標系での min 点 |
| `scale_max_rel_x`, `scale_max_rel_y` | ARマーカー座標系での max 点 |
| `scale_direction` | min から max への回転方向 |
| `registration_scale_min_x`, `registration_scale_min_y` | 登録時画像上の min 点 |
| `registration_scale_max_x`, `registration_scale_max_y` | 登録時画像上の max 点 |

## 登録処理の流れ

1. 画像を開く
2. 必要に応じて `処理最大幅` でリサイズする
3. ARマーカーを検出する
4. メーター円を設定する
   - 手動で中心・半径を指定
   - または `メーター円を自動検出`
5. min/max 目盛りを設定する
   - 画像クリックで手動指定
   - または `目盛りを自動設定`
6. `この円と目盛りで登録保存` を押す
7. ARマーカー座標系に変換したメーター円と目盛り情報を JSON に保存する

min/max 点は、保存前に現在の緑色のメーター円枠線上へ射影されます。そのため、クリック位置が円の内側や外側でも、登録される点は円周上になります。

## 検出処理の流れ

`登録から針と値を検出` を押すと、次の流れで処理します。

1. 登録情報が未読み込みの場合は JSON から読み込む
2. 現在画像から ARマーカー検出を試す
3. ARマーカーが見つかった場合
   - 登録済みの相対位置からメーター円を復元する
   - ホモグラフィ変換で傾きを補正した画像を作る
   - 補正後画像上で針を検出する
   - 検出した針先を元画像座標へ戻す
4. ARマーカーが見つからない場合
   - 現在 GUI 上で保持しているメーター円を使う
   - その円だけを基準に針を検出する
5. min/max 目盛りが登録済みの場合
   - 針角度が min から max のどこにあるかを計算する
   - `scale_min_value` から `scale_max_value` の範囲へ線形補間する
6. プレビューを更新し、結果画像を保存する

## 針検出の前提

登録後の通常検出では、メーター本体を毎回画像から探しているわけではありません。

メーター位置は次のどちらかで決まります。

- ARマーカーが検出できた場合: 登録済みの ARマーカー相対位置から復元する
- ARマーカーが検出できない場合: GUI 上の登録済み円情報を使う

メーター円を画像から探す処理は、`メーター円を自動検出` ボタンや登録時の補助処理として使います。

## 描画仕様

プレビューでは次を描画します。

| 描画 | 色 / 内容 |
| --- | --- |
| メーター円 | 緑 |
| メーター中心 | 青 |
| 針 | 赤線 |
| 針先の赤点 | 初期設定では非表示 |
| ARマーカー枠 | 紫 |
| min 点 | 黄 |
| max 点 | オレンジ |
| 文字列 | チェックボックスで表示切替 |

描画の太さや点サイズは `detect_meter_needle_ar_marker.py` の定数で変更します。

| 定数 | 初期値 | 内容 |
| --- | --- | --- |
| `DEFAULT_DRAW_LINE_THICKNESS` | `1` | 線の太さ |
| `DEFAULT_DRAW_POINT_RADIUS` | `8` | min/max 点の半径 |
| `DEFAULT_DRAW_NEEDLE_TIP_POINT` | `False` | 針先の赤点を表示するか |

## 座標系

このアプリでは複数の座標系を使います。

| 座標系 | 内容 |
| --- | --- |
| 元画像座標 | 読み込んだ画像そのものの座標 |
| 処理画像座標 | `max_width` に合わせてリサイズした後の座標 |
| 表示座標 | Qt 画面上に拡大縮小表示された座標 |
| ARマーカー座標 | マーカー平面を基準にした相対座標 |
| 補正画像座標 | ホモグラフィでメーター面を正面化した座標 |

`ImageView` は表示座標から処理画像座標への変換を担当します。  
ARマーカー基準の保存や復元は、`detect_meter_needle_ar_marker.py` のホモグラフィ変換関数が担当します。

## 注意点

- 登録後の検出では、ARマーカーが見つかることを基本想定しています。
- ARマーカーが見つからない場合は、現在 GUI 上にあるメーター円情報で処理します。
- min/max が未登録の場合、針の角度は出せますが指示値は計算できません。
- min/max 点は円周上に射影されるため、点を円内に打っても表示・保存時は緑の円枠上になります。
- 文字列を非表示にしても、円、針、ARマーカー枠、min/max 点は描画されます。
